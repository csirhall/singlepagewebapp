**CALCULATING AGE: CS39-AF SPA PROJECT**

**Overview: Application overview and purpose**

This is a single page application (SPA) that displays a person's age in years, days, and months. It uses simple HTML, CSS, and JS to display the age.
The purpose of this application is to demonstrate the ability to write a very simple 
SPA without the use of generative AI and to understandthe basics of HTML, CSS, and JS. 

**Functionality: Features and functionality description**

The age calculator utilizes HTML, CSS, and JS to display a person's age. 
It uses HTML to display a form for a user to input their birthdate using a calender selection. 
It then uses paragraph types and IDs for JS to call from. 
Using JS, I used a function and two constructors: current_date and dateInput, 
to calculate the age of a person in years, months, and days. 
Finally, it utilizes CSS to style different colors and layouts to make the SPA look nicer. 

**Choices and Challenges: Development process choices and challenges**

I started the development process by first brainstorming ideas 
for a simple single page application. After I decided on a age calculator, I begin designing the
basic layout with HTML using various header and paragraph tags as well as including an image. 
I then began research into how to incorporate JavaScript functions to get the 
calculator to work. I finally added some styling to the webpage and played around 
with different colors, margins, and layouts. There were many challenges throughout this project. 
One of the major challenges was learning how to use JavaScript as I was not familar with it. 
It was also challenging to get the functions working and learning how to use the various methods 
in JavaScript. 
It was challenging to calculate a user's age and incorporate math and programming 
elements together.
