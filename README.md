Overview:

This is a single page application (SPA) that displays a person's age in years, days, and months. It uses simple HTML, CSS, and JS to display the age.
The purpose of this application is to demonstrate the ability to write a very simple SPA without the use of generative AI and to understand
the basics of HTML, CSS, and JS. 

Functionality:
The age calculator utilizes HTML, CSS, and JS to display a person's age. It uses HTML to display a form for a user to input their birthdate.
